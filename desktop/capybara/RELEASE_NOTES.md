卡皮巴拉 0.1.7 正式版

- 点击首页右侧节点即可连接，无需再点击“一键连接”；断开后点击当前节点也能恢复连接。
- 已连接时点击其他节点直接切换，连接按钮跟随实际状态，仍可手动断开。
- 选择和连接期间显示处理中，防止重复点击；节点失效或连接失败显示真实原因，避免误连旧节点。
- 修复操作前发出的旧状态查询可能覆盖最新连接状态的问题。

登录、加载节点、测速和仅切换分流模式仍不会自动开启系统代理。全局模式作用于进入代理的新连接；现有浏览器连接可能沿用旧出口，必要时重新打开浏览器。

Linux 自动代理覆盖 GNOME，DEB 使用系统安装器升级；不含 TUN。更新签名不等同于 Windows 发行者签名或 macOS Developer ID 公证。
