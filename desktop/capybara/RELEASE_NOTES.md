卡皮巴拉 0.1.0 正式版

- 修复网页已确认授权、客户端仍提示“服务暂时不可用”的问题：服务端在数据库写竞争后完整回滚并有限重试，客户端保留已批准的等待状态。
- 保留蓝色山水旅行水豚首页，节点列表直接放在首页右侧，支持搜索、地区筛选和分流组切换。
- 支持官网账号登录与注册、套餐购买、账户用量、系统代理连接和连接检测。
- 应用运行时每 6 小时检查新版本，发现后提示确认更新；选择“稍后”后，帮助页保留“查看更新”按钮，也可随时立即检查。
- 正式版本移除 Alpha 和测试版标记；官网安装包与签名更新源在附件验证后同步。

当前通过系统代理连接，不含 TUN；Linux 自动代理仅覆盖 GNOME，DEB 使用系统安装器升级。更新签名验证包来源和完整性，不等同于 Windows 发行者签名或 macOS Developer ID 公证。
