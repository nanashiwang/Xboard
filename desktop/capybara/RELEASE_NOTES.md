卡皮巴拉 0.1.1 正式版

- 登录后自动加载当前账号套餐下的节点，无需先开启连接；可提前选择节点，断开后保留列表和选择。
- 节点切换立即显示处理状态，本地内核确认后更新选中项，不再等待外网连通检测和账号刷新。
- 首页新增“一键测速”，逐个显示真实延迟或超时/不可达；最多四路并发，测速不启用系统代理。
- 帮助与设置新增“开机自启”开关；登录系统后后台启动，不自动连接。关闭窗口后继续后台运行，可从托盘重新打开或退出。
- 保留正式版网页授权登录、套餐购买和每 6 小时更新检查；发现新版后提示，帮助页可查看更新。

延迟表示本机经节点访问检测站点的耗时，随网络变化，不等同于下载带宽。当前通过系统代理连接，不含 TUN；Linux 自动代理覆盖 GNOME，托盘需要桌面支持，DEB 使用系统安装器升级。更新签名验证包来源和完整性，不等同于 Windows 发行者签名或 macOS Developer ID 公证。
