卡皮巴拉 0.1.4 正式版

- 一键连接按钮恢复到首页左侧，避免遮挡卡皮巴拉；小窗口及提示横幅出现时紧凑适配，保留节点列表独立滚动。
- 首页新增“规则 / 全局 / 直连”三种分流模式；内核运行时确认并应用，未运行时先保存、下次准备节点生效，重新启动和刷新订阅继续使用。
- 全局模式提供独立的出口选择，避免切换为全局后仍默认直连。
- 新增“管理规则”：支持域名、域名后缀、IPv4/IPv6 网段，可指定走节点或分流组、直连、拦截；支持编辑、删除和调整优先顺序。
- 自定义规则仅在规则模式生效，按列表从上到下优先于套餐规则；校验和保存失败保留原配置并提示。
- 保留通知铃铛、邀请好友、适应窗口高度的首页，以及账号授权登录、套餐购买、自动加载节点、一键测速、开机自启与每 6 小时更新检查。

分流只影响交给系统代理的流量；切换后新连接使用新规则，已有连接可能继续使用原出口。直连模式不等于关闭系统代理。当前不含 TUN、任意 YAML 编辑、外部规则集或进程规则。Linux 自动代理覆盖 GNOME，DEB 使用系统安装器升级；更新签名不等同于 Windows 发行者签名或 macOS Developer ID 公证。
