卡皮巴拉 0.1.2 正式版

- 新增系统通知铃铛，同步官网公开公告，支持未读提示、通知详情、分页、刷新和本页已读；每五分钟及回到窗口时检查新内容。已读保存在本机，公告更新后重新提醒。
- 新增“邀请好友”：查看和生成本人邀请码，复制邀请链接、展示分享二维码，查看注册人数、佣金统计与分页明细；邀请额度、有效期和奖励比例与官网一致。
- 首页适配窗口高度，主界面保持固定，仅节点列表内部滚动；最小窗口仍可使用连接按钮、查看流量和一键测速。
- 保留账号授权登录、套餐购买、登录后自动加载节点、一键测速、开机自启与每 6 小时更新检查。

邀请需要官网配套接口，提现和余额划转仍在官网办理。系统公告内容与官网同步，已读标记仅本机。

当前通过系统代理连接，尚不支持 TUN。Linux 自动代理覆盖 GNOME，DEB 使用系统安装器升级；更新签名不等同于 Windows 发行者签名或 macOS Developer ID 公证。
