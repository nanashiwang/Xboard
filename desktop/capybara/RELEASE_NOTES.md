卡皮巴拉 0.1.0-alpha.9 新增注册账号入口。

- 未登录首页与登录等待页可点击“注册账号”，使用默认浏览器打开官网注册流程。
- 注册完成后自动返回授权页，确认账号即可登录客户端；复用官网邮箱验证码、邀请码及注册限制。
- 官网已有登录状态时先展示当前账号供确认，不自动退出或切换账号；授权过期后可用已注册账号重新登录。
- 保留账号浏览器登录、套餐购买和支付、自动更新、流量同步及系统代理能力。

需要官网同步更新授权页面脚本；配套授权接口与数据库表不变。注册码、密码与验证码只在官网填写，客户端仅保存既有设备登录凭据。更换临时签名构建后可能需要重新授权一次。

Alpha 不含 TUN；Linux 自动代理仅覆盖 GNOME；更新签名不等于 Windows 发行者签名或 macOS Developer ID 公证。
