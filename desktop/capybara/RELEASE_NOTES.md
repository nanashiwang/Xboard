# 卡皮巴拉 0.1.24

- 新登记的家宽出口通过验收后即可连接，代理详情显示实际登记地区。
- 管理员可在「家宽订阅与容量」登记出口、复制安装命令并执行单机验收。

## 0.1.23

- 新增「钱包」，可查看与网页版共用的消费余额，以及最近 10 笔使用余额的套餐订单。
- 购买套餐时优先抵扣钱包余额，余额足够可直接确认开通，不足时支付差额。取消待支付订单后可查看退回金额。

## 0.1.22

- 打开客户端后会提前读取套餐，来回切页可直接查看已有列表和已选周期。
- 再次进入时，超过一分钟的目录在后台更新。读取失败会自动重试，已有套餐卡片仍可浏览。

## 0.1.21

- 账号入口预检允许较慢的网络响应，已验证入口可跨多个同步周期复用。
- 最近 90 秒内成功同步过套餐时，偶发网络超时会在后台重试。持续失联、首次读取失败或套餐已到期时仍及时提示。

## 0.1.20

- 精简分流面板，移除规则模式说明和模式按钮下方的系统代理提示。

## 0.1.19

- 一键测速分别显示「入口」TCP 延迟和「联网」HTTPS 检测结果。共用入口只连接一次，六条实际节点可同时检测，策略组不再占用测速名额。
- 测速期间逐条显示结果。入口没有真实解析地址时会明确提示，仍可查看该节点的联网结果。
- 更新订阅时仍会核对账号和套餐。配置未变化且内核正常时保留当前配置和测速结果。配置有变化时照常校验和应用。

## 0.1.18

- 点击「连接此代理」会经第一阶段连接已购家宽端口。只购买家宽也可以使用，网站看到的仍是已购固定 IP。
- HTTP 和 SOCKS5 都会验证实际出口和网站连通性。首页显示第一阶段及出口 IP，普通套餐到期或流量用尽时家宽可以继续使用。

## 0.1.17

- 点击「连接此代理」会优先经本人普通套餐线路连接已购家宽。当前线路连不上时，客户端最多尝试三条线路，公网出口仍是已购固定 IP。
- 通过 HTTPS 核对公网出口后才开启系统代理。首页和家宽详情显示实际中转线路，首页的「连接检测」支持复检家宽出口。
- 普通线路按原套餐计量。仅购买家宽代理的账号仍可从入口可达的网络直连。

## 0.1.16

- 将「我的代理」统一改名为「家宽代理」，官网和客户端使用一致的名称。
- 官网家宽代理嵌入用户中心，概览、详情和购买流程保留原有侧栏与页头，点击菜单不再跳到独立页面。
- 调整官网内容留白、标题、卡片和按钮配色，适配桌面与手机菜单。
- 页面切换时清理轮询和连接信息；资源加载失败支持重试，旧代理链接兼容返回用户中心。

代理价格、端口、认证和既有连接方式保持不变。

## 0.1.15

- 新增「我的代理」：独立购买、续费和管理家宽固定代理，月付 ¥39、每端点最高 100 Mbps、不限累计流量。
- 支持查看连接地址、端口、用户名和密码，选择 SOCKS5 或 HTTP，一键连接或断开。
- 代理权益与原 VPN 套餐分开管理，购买代理不会覆盖原订阅或扣减 VPN 流量。
- 支持重命名、重置认证和恢复待支付订单；到期或认证变更后停止旧代理连接。
- 官网用户中心同步增加「我的代理」入口，沿用现有余额和支付方式。

HTTP 支持 HTTPS CONNECT；本版代理不提供 UDP 转发。100 Mbps 是单端点限速上限，实际速度取决于网络。到期代理保留归属以便续费，未自动复售。

## 0.1.14

- 主服务连接失败时自动选择 Hub 备用服务，继续登录、同步套餐和更新订阅。
- 应用更新支持 Go 与 Hub 双更新源；安装包下载失败时切换备用来源，继续验证原发行签名。
- 支持验证、缓存签名入口清单，后续更换服务域名无需再次修改客户端。
- 网络或 CDN 错误不会仅因返回 401/403 而清除登录记录；登录续期和订单等操作不盲目重放。
- Hub 导航增加备用官网入口和独立下载通道。

请趁现有入口可用时升级。旧版本需要能够访问旧更新源，或从导航页覆盖安装。本版不包含第三方客户端自动切换、离线授权或后台服务器容灾。
