卡皮巴拉 0.1.8 正式版

- 修复 Windows 下浏览器可用，而 YuanHeng/Codex 等原生 HTTP 应用未能识别系统代理、请求直连超时的问题。系统代理改用统一地址，规则与全局模式均适用。
- 兼容旧版代理恢复记录，退出、断开及升级时仍恢复原设置；用户后来改用其他代理时不覆盖。
- 包含 0.1.7 的节点连接改进：点击首页右侧节点即可连接，已连接时直接切换，断开后点击当前节点可恢复，连接按钮跟随实际状态。
- 选择与连接期间防重复点击；失败显示真实原因，旧状态查询不覆盖最新连接结果。

Windows 更新后请断开再连接，让新格式生效。源码与自动化回归验证代理格式兼容性，用户现场的真实 Codex /responses 请求仍需复验；应用自带的显式代理或环境代理设置仍按应用自身规则处理。

登录、加载节点、测速和仅切模式不自动连接。全局模式作用于进入代理的新连接，已有连接可能沿用旧出口。Linux 自动代理覆盖 GNOME，DEB 使用系统安装器升级；不含 TUN。更新签名不等同于 Windows 发行者签名或 macOS Developer ID 公证。
