卡皮巴拉 0.1.0-alpha.8 新增客户端套餐购买。

- 侧栏“我的账户”改为“套餐”，展示可购买套餐、流量、设备上限与周期价格；账户资料仍从左下角进入。
- 支持选周期、填写优惠码、创建订单，复用网站的折扣、余额抵扣、原套餐折抵与续费规则；确认最终金额后选择支付方式。
- 支持在浏览器付款或客户端展示支付二维码，恢复待支付订单、取消订单、零元开通与支付状态自动刷新；服务器确认开通后才同步权益。
- 增加明暗主题、窄窗口、空列表和网络失败状态；写请求失败不自动重复下单，支付响应中的 HTML 不在客户端执行。

需要服务器部署本版 Desktop 套餐/订单接口。浏览器授权登录仍需要 alpha.6 的接口与 client_browser_logins 迁移；仅安装客户端不能补齐服务器能力。生产部署、真实付款和官网更新源独立验收，见仓库 README 与 progress-log。

保留账号浏览器授权、蓝绿色图标、每六小时检查更新、签名校验、流量同步、线路选择和系统代理。更换临时签名构建后可能需要重新登录。Alpha 不含 TUN；Linux 自动代理仅覆盖 GNOME；更新签名不等于 Windows 发行者签名或 macOS Developer ID 公证。
