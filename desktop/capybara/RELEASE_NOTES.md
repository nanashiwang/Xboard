卡皮巴拉 0.1.0-alpha.4 优化 macOS 钥匙串授权体验。

- macOS 打开应用时静默恢复登录，不再主动弹出钥匙串密码框；已有权限时仍可自动恢复。
- 钥匙串锁定或尚未授权时，显示“登录记录等待授权”。点击“恢复登录”后才请求系统授权，也可以重新输入账号密码登录。
- 后台账号同步、令牌更新和失败清理不会反复触发钥匙串授权。授权失败后保留明确提示和手动重试入口。
- macOS 登录记录按当前应用构建隔离，重新登录不再读取旧版受限记录。升级到本版需重新登录一次账号；同一安装版本后续启动会自动恢复。临时签名下更换构建可能仍需重新登录账号。
- 登录记录继续由系统凭据库保护；登录窗口说明系统密码只在 macOS 弹窗中输入。
- 保留每 6 小时检查更新、确认后验签安装、流量同步、线路选择和系统代理功能。

旧 alpha.1 / alpha.2 还没有更新功能，需要先手动安装本版本一次。

这是 Alpha 测试版。更新包签名用于验证来源，不等于 Windows 发行者签名或 macOS Developer ID 公证；系统仍可能提示未知发布者。当前为系统代理，暂不支持 TUN；Linux 自动代理仅覆盖 GNOME/gsettings。跨系统真实安装升级和长期网络体验仍需试用验收。
