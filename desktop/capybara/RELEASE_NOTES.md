卡皮巴拉 0.1.6 正式版

- 首页节点列表新增“更新订阅”，点击后立即下载并应用最新配置，无需等待自动更新周期。
- 单独显示订阅配置的上次成功更新时间，避免与每30秒刷新的流量和套餐状态混淆。
- 帮助与设置新增订阅更新周期，默认每1小时，可选择30分钟或3、6、12、24小时，重开应用保留设置。
- 更新失败显示原因并保留上一份有效配置；更新后继续使用有效的节点选择和本地分流规则。登录失效或套餐不可用仍会停止连接。
- 自动更新由客户端后台执行，休眠恢复后检查是否到期；手动更新不改变系统代理开关。

订阅更新成功表示最新配置已应用，不代表所有节点连接可用。服务器端的线路、公钥或地址故障仍需独立处理。本次不修改生产外接节点配置。

Linux 自动代理覆盖 GNOME，DEB 使用系统安装器升级；更新签名不等同于 Windows 发行者签名或 macOS Developer ID 公证。
