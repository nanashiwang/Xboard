卡皮巴拉 0.1.0-alpha.6 支持浏览器授权登录。

- 点击登录打开默认浏览器，复用 taige.us 官网已登录账号；未登录先登录官网，完成后自动回到授权页。
- 确认当前账号与设备后，客户端自动完成登录并回到前台；无需在客户端输入网站密码。
- 支持取消授权、重新打开浏览器和失败重试，授权五分钟过期；网页登录令牌不会传给客户端，桌面授权只兑换一次。
- 保留设备数量限制、系统凭据库和 alpha.4 的钥匙串静默恢复；包含 alpha.5 蓝绿色图标。更换临时签名构建后需重新授权一次，同一构建可继续自动恢复。
- 账户网络错误区分连接失败、超时和系统拒绝，便于排查；此改动不代表所有网络环境已经验收。

需要官网部署本版浏览器授权接口及数据库迁移后才能完成登录。生产部署与 GitHub Release 独立记录，部署状态见仓库 README 和 progress-log。

保留每六小时检查更新、用户确认后验签安装、流量同步、线路选择和系统代理。Alpha 版暂不支持 TUN；Linux 自动代理仅覆盖 GNOME。更新签名不等于 Windows 发行者签名或 macOS Developer ID 公证，跨平台真实安装与账号仍需验收。
