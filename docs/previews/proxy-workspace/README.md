# 家宽代理工作区 · 交互设计预览

用户确认本轮先交付官网概览、代理详情与客户端预览。服务器端点部署另行授权、独立验收，预览不接入真实服务端。

打开 [index.html](index.html)；也可以在项目根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory docs/previews/proxy-workspace
```

访问 `http://127.0.0.1:8767/`，顶部导航切换三页。所有资源本地提供，无外部字体、CDN 或业务 API；图标复用客户端既有资产。直接打开文件时，剪贴板受浏览器限制会提供手动复制。

- **概览 `#overview`**：状态统计、名称/IP/编号搜索、到期排序、状态筛选、选择与导出、模拟购买。窄屏表格转换为代理卡片。
- **详情 `#detail/p01`**：连接信息优先、同端口 SOCKS5/HTTP 切换、逐项与多格式复制、密码显示/确认重置、重命名、手动续费、累计用量与趋势、检测示意和连接指南。
- **客户端 `#client`**：保持 VPN 入口，增加“我的代理”；端点选择、协议选择、模拟连接/断开、失败及空列表场景、详情与续费衔接。列表独立滚动，避免占满客户端窗口。

产品显示“家宽固定 IP”，39 元/月、最高100 Mbps、不限累计流量。用户要求主界面不强调十端口分配方式，不宣称独享IP、保底速度、住宅ISP认证或100%可用率。两种协议是同一端点的不同用法，不创建两份订单。

示例地址使用文档保留的 `203.0.113.10`，密码均为虚构。状态仅保存在当前页面内存，刷新恢复。数据基准为北京时间2026-11-18；预览内续费增加一个日历月。未开通不显示凭据，到期不允许连接；新增模拟购买保持待开通，不伪造交付。

已检查1440px桌面及390/320/760/1180px三路由无横向溢出；筛选、空结果、协议同步、密码显示/隐藏、重命名转义、重置取消、续费、连接/断开/失败、待开通和空列表交互通过。没有操作真实账号、扣款、系统代理或正式客户端安装包。
