# 固定分配美国出口套餐

套餐定义位于 `.docker/dedicated/plan.json`：美国独享家宽IP、59 元/月、200 GB/月、10 Mbps，不限制在线公网 IP。公共线路与固定出口共用流量，固定出口 1 倍率；首批容量 15 个账号，只开放月付。此名称沿用运营配置，IP 属性需由运营方核实。

每个物理出口最多绑定 5 个有效订阅账号，后端保留唯一的出口/槽位和账号约束。下单预留名额 2 小时，取消或超时释放；已支付待开通的订单持续占位。流量耗尽不释放仍在有效期内的绑定。正常续费保留出口；到期后续费需重新取得可用名额。

套餐售罄时从新购列表隐藏，已订阅用户可通过原套餐详情续费。数据库事务锁串行分配同一套餐的名额，SQLite 与 MySQL 均适用。普通用户只能认证公共节点；购买用户只能认证公共节点及分配的出口。订阅过滤、REST 用户列表和 WebSocket 增量同步使用同一绑定规则，复制别人的节点地址也不会获得授权。

## 部署与上架

1. 备份 SQLite 数据库（在线 backup 并检查完整性）、`.env`、Compose、插件、主题和入口 Nginx 配置。
2. 发布镜像并通过现有生产更新流程执行迁移，核实容器 OCI revision。
3. 在服务器本地准备权限 0600 的 JSON 清单，字段为 `backend_template_id`、`frontend_template_id`、`port_start`、`exits`；每个出口包含 `ip`、`port`、`username`、`password`、`standby`。模板必须是同一条 VLESS WebSocket 入口的后端和公开节点。不得把私密清单上传仓库或输出日志。
4. 执行 `php artisan dedicated:prepare <私密清单>`，创建隐藏套餐和各出口的后端/前端节点。命令可重复执行，不重复创建或自动开放销售，也不覆盖已存在的价格、凭据或绑定。
5. 在入口 Nginx 为新节点的 WebSocket 路径配置回环转发，保留现有访问控制。先 `nginx -t` 再 reload；后端端口不向公网开放。
6. `php artisan dedicated:check` 校验后端心跳和经 SOCKS5 的真实 HTTPS 出口 IP；连续两次成功后标记健康。用专门测试账号逐条验证客户端 TLS → WebSocket → VLESS → 美国出口，核对流量入账和未授权账号拒绝；测试结束撤销账号。
7. 所有销售出口与备用出口验收通过后，再开启套餐 `show/sell`。生产新购只开放已验证容量，不能靠添加套餐卡片代替代理通路验证。核对普通用户套餐页面、月付金额和新购/续费流程，不进行真实付款。

### 入口首次开通修复

生产 `xboard-node` 基于上游 `0a29338e1f102a462363ce3527417029f89bab28`。此版本在零用户启动后，先检查旧用户列表能否启动内核，再应用新用户；因此首个用户购买后，专属端口仍不监听，入口返回 502。

`.docker/dedicated/node-idle-start.patch` 修复全量同步和增量新增两条路径：先准备新用户状态再启动内核，失败时还原用户和限速状态。使用 Go 1.26.2 执行 `bash .docker/dedicated/build-node.sh /绝对路径/xboard-node-linux-amd64`，生成 `0a29338-dedicated.1`，保持生产构建标签。脚本只构建，不修改线上服务。

部署前备份入口程序及配置，核对上传二进制哈希，再替换程序并重启 `xboard-node`。验收必须包含“空节点启动 → 新增首个用户 → 无重启建立代理连接”，同时检查原有公共节点；只重启旧程序会暂时掩盖问题。回退时恢复备份程序并重启。

## 健康和故障处理

调度器每分钟运行 `dedicated:check`。连续三次失败后停止分配该出口；连续两次恢复后重新纳入可用资源。健康信息超过 5 分钟未刷新也会停止分配。首批使用 3 个销售出口和 2 个备用出口，避免将故障迁移所需容量卖出。

后台检查或用户更新订阅时，在不超过每个出口 5 个账号的前提下迁移绑定；恢复后不主动迁回原 IP。新、旧节点同步撤销或增加账号，REST 轮询同步间隔以现有节点设置为准。备用容量不足时保留原绑定等待恢复，公共线路仍可使用，不挤占已满出口。

`php artisan dedicated:status` 显示健康与占用。迁移/预留/释放记录保存在 `v2_dedicated_assignment_log`，不含用户密码或代理凭据。排查故障应同时检查健康检查调度、节点心跳、Nginx 和真实代理请求，不能仅凭 443 端口可连接判定出口可用。

暂停新购时设置套餐 `sell=false`；已有用户授权继续按有效订阅执行。不要通过恢复整库来回退商品文案或配置，以免覆盖新增订单和用量。

## 验证

`tests/Feature/Dedicated` 覆盖并发抢购、预留过期、续费、支付待开通、流量耗尽、到期释放、订阅隔离、REST/WS 授权、故障迁移及准备命令幂等。并发测试启动 8 个独立 PHP 进程争抢同一 SQLite 数据库中的 5 个名额，验证仅有 5 笔订单与绑定成功。
