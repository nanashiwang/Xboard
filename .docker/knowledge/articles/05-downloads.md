# 卡皮巴拉客户端下载与安装

**[打开客户端下载页](/clients)**，按设备选择安装包。电脑端优先使用我们开发的卡皮巴拉，安装后用本站账号登录，无需复制订阅链接。

## 一、电脑端：安装后直接登录

- **Windows**：[下载卡皮巴拉](/clients#windows)，支持 Windows 10 / 11 x64。
- **macOS**：[下载卡皮巴拉](/clients#macos)，需要 macOS 12 或更新版本。在苹果菜单 → 关于本机查看芯片，选择 Apple 芯片版或 Intel 版。
- **Linux**：[下载卡皮巴拉](/clients#linux)，提供 x64 DEB 与 AppImage。自动代理目前只支持 GNOME / gsettings，需要桌面会话及系统密钥环；其他桌面或 ARM 设备请使用适配的第三方客户端。

1. 下载安装包并打开卡皮巴拉。
2. 使用本站账号登录，确认套餐有效且有剩余流量。
3. 先关闭其他代理客户端，再选择线路并点击连接。
4. 实际打开需要使用的网站，确认连接正常。

卡皮巴拉每 30 秒同步剩余流量和到期状态，连接期间每小时更新线路配置。流量耗尽或套餐到期会明确提示；计费上报可能有延迟，不能当作逐字节实时用量。

从 alpha.3 起，卡皮巴拉每 6 小时检查应用新版本，帮助与设置中也可立即检查。发现新版会先询问，选择“稍后”不会下载，帮助与设置保留“查看更新”按钮；确认后才下载并校验更新包，安装前断开连接、恢复系统代理。Windows、macOS 和 Linux AppImage 支持应用内更新，DEB 会打开官网下载页，由系统安装器完成安装。旧 alpha.1 / alpha.2 需要先手动升级一次。

当前为 0.1.0 正式版，通过系统代理连接，尚不支持 TUN。更新包签名不等于 Windows 发行者签名或 macOS 开发者公证，系统仍可能显示安装或打开提示。不确定时可使用下方第三方方案。

## 二、手机端：使用第三方客户端

目前没有卡皮巴拉手机版。

- **Android**：[下载 Clash Meta for Android](/clients#android)，多数手机选择 ARM64，不确定架构时选择通用版。
- **iPhone / iPad**：[安装 sing-box](/clients#ios)，通过 App Store 安装；注意页面上的系统版本及账户地区要求。

安装并打开客户端一次，然后在浏览器登录本站，回到对应设备的下载页，点击“一键导入”。在客户端确认保存并选中订阅，按提示创建 VPN 配置，再开启连接。

## 三、已有 Clash 或需要其他电脑端方案

[第三方桌面客户端下载与导入](/clients#clash-verge)保留 Clash Verge Rev。此类客户端需要导入订阅，不能使用卡皮巴拉的账号登录流程。

一键导入没有反应时，点击“复制订阅地址”，在客户端添加 URL / 远程订阅。自动复制不可用时，展开“手动导入地址”自行复制。内置浏览器无法拉起客户端时，改用系统浏览器。导入后仍需保存、选中配置并开启连接。

## 四、下载与安全提醒

安装包版本、大小、校验值和官方备用链接统一在下载页查看。下载无需登录，第三方个人订阅只向已登录且订阅有效的账号提供。

- 不要公开个人订阅地址、密码或完整诊断凭据。
- 升级已有客户端前保留需要的配置，不必先卸载并删除全部数据。
- 下载异常时使用“官方备用下载”；仅安装与系统和芯片匹配的版本。
