# 开源客户端下载与一键导入

**[打开客户端下载页](/clients)**，按设备选择安装包，安装后直接导入你的订阅。

也可以从用户中心侧栏的“客户端下载”，或仪表盘的“下载与导入”进入。本站目前接入现有开源客户端，不提供自研客户端；旧教程中提到的“定制客户端（快加速）”不属于当前下载入口。

## 一、按设备选择

- **Windows**：[下载与导入 Clash Verge Rev](/clients#windows)。当前本站包适用于 Windows 10 / 11、x64。
- **macOS**：[下载与导入 Clash Verge Rev](/clients#macos)。需要 macOS 11 或更新版本；按 Apple 芯片或 Intel 芯片选择。
- **Android**：[下载与导入 Clash Meta for Android](/clients#android)。多数手机选择 ARM64，不确定架构时选择通用版。
- **iPhone / iPad**：[安装与导入 sing-box](/clients#ios)。通过 App Store 安装，注意系统版本及账户地区要求。
- **Linux**：[下载与导入 Clash Verge Rev](/clients#linux)。本站提供 AMD64 的 DEB 包，面向 Debian / Ubuntu 系；还需满足安装包依赖。

安装包版本、大小、校验值和官方备用下载统一在下载页查看，避免教程与安装包版本不同步。其他架构或 Linux 发行版请使用页面上的“其他版本与架构”入口，并核对官方兼容性要求。

桌面和安卓的本站安装包可以直接下载；iOS 使用 App Store 安装。下载页无需登录，获取个人订阅需要登录且订阅可用。

## 二、安装后这样导入

1. 安装对应客户端，并手动打开一次。
2. 在浏览器登录本站，回到对应设备的下载页。
3. 点击“一键导入”，在浏览器提示中允许打开对应客户端。
4. 在客户端确认保存，并选中刚导入的订阅配置。
5. 选择节点并开启连接：桌面端按客户端说明开启系统代理，移动端允许该客户端创建 VPN 配置。
6. 实际打开需要使用的网站，确认连接是否正常。

一键导入只是把订阅交给客户端，不能代替最后的保存、选中配置和连接步骤。

## 三、一键导入没有反应

点击“复制订阅地址”，在客户端新建 URL / 远程订阅后粘贴保存。无法自动复制时，可以展开“手动导入地址”自行复制。微信等内置浏览器无法拉起客户端时，请改用系统浏览器。

完整步骤见“订阅操作指南”；报错或节点无法连接时，查看“导入失败怎么办？用不了，或者只有几个节点的看这里”。

## 四、安装与升级提醒

- macOS 可在“苹果菜单 → 关于本机”查看芯片类型。
- Windows ARM、其他 Linux 发行版和旧系统不要直接安装不匹配的包，请核对官方下载说明。
- 已有客户端配置时，先保留需要的设置，再按客户端说明升级；通常不需要先卸载并删除全部数据。
- 本站下载异常时，可使用下载页的“官方备用下载”。
- 个人订阅地址包含账号的访问凭据，不要公开分享或粘贴到不可信的转换网站。
