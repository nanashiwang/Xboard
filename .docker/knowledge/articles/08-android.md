# 安卓：使用 Clash Meta for Android

**[打开安卓下载与导入页面](/clients#android)**。本站接入的是 Clash Meta for Android（CMFA），请注意与旧版 Clash for Android 区分。

## 一、下载安装

1. 多数较新的安卓手机选择 ARM64 包；不确定架构、使用模拟器或旧设备时，可以选择通用版。
2. 按安卓系统提示安装，并手动打开一次客户端。
3. 回到浏览器，在本站登录自己的账号。

下载页同时提供官方备用链接和安装包校验值。安装失败时先核对系统版本、架构和系统显示的原因。

## 二、一键导入订阅

1. 在安卓下载页点击“一键导入 Clash Meta for Android”。
2. 浏览器询问是否打开应用时，确认客户端后允许打开。
3. 在客户端检查订阅信息，完成下载 / 保存。
4. 在配置列表选中刚导入的配置。

如果是在微信等内置浏览器中打开，请切换到系统浏览器重试。

## 三、手动添加 URL 配置

一键导入没有反应时：

1. 在下载页点击“复制订阅地址”；无法自动复制时展开“手动导入地址”自行复制。
2. 打开 CMFA，进入“配置”，新建配置并选择 URL。
3. 粘贴完整订阅地址，填写一个便于识别的名称，下载并保存。
4. 选中刚添加的配置。

不同版本的界面文字可能略有差异。请复制下载页给出的个人地址，不要复制本教程地址、安装包链接或“你的订阅链接”等文字。

## 四、启动连接并选择节点

1. 回到客户端主界面，启动连接。
2. 系统弹出 VPN 连接请求时，确认是 CMFA 后按提示允许。
3. 进入代理 / 节点页面，测试延迟并选择节点。
4. 实际打开需要使用的网站，验证连接效果。

安卓使用客户端建立的 VPN 连接，不是桌面端的“系统代理”开关。仅选中一个节点不会自动完成全部连接步骤。

## 五、更新和断开

在配置页面更新远程订阅，以获取最新节点。若本站重置了订阅链接，需要重新获取地址并替换旧配置。

不用时在客户端停止连接。连接失败时检查套餐有效期、剩余流量、客户端版本及当前网络；详细排查见“导入失败怎么办？用不了，或者只有几个节点的看这里”。
