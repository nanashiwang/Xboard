# 其他设备、系统和架构的使用说明

先查看 [客户端下载页](/clients)。本站当前接入现有开源客户端，提供下载和订阅导入入口；不提供自研或“快加速”定制客户端。

## 一、当前下载页覆盖的平台

- **Windows 10 / 11**：[Clash Verge Rev](/clients#windows)。本站包为 x64，ARM 设备需核对官方下载。
- **macOS 11 或更新版本**：[Clash Verge Rev](/clients#macos)。区分 Apple 芯片和 Intel 芯片。
- **Android**：[Clash Meta for Android](/clients#android)。提供 ARM64 和通用版，按系统版本及架构选择。
- **iPhone / iPad**：[sing-box](/clients#ios)。通过 App Store 安装，核对系统及账户地区要求。
- **Linux 桌面**：[Clash Verge Rev](/clients#linux)。本站提供 AMD64 DEB 包，面向 Debian / Ubuntu 系，需满足依赖。

具体版本、系统要求和备用下载以下载页及对应项目的官方说明为准。

## 二、其他 Linux 发行版、架构与无桌面环境

DEB 包并不适用于所有 Linux 发行版。ARM 设备或其他发行版请从下载页的“其他版本与架构”入口核对相应安装包。

无图形界面的服务器不能直接照搬桌面安装与系统代理步骤。使用 mihomo 或 sing-box 等内核时，需要自行管理配置格式、运行权限、服务启动和订阅更新；本站的一键导入按钮不能替你完成这些配置。

## 三、旧版 Windows / macOS

当前本站提供的 Clash Verge Rev 安装包不面向 Windows 7 / 8 或 macOS 11 以下系统。不要将“有下载链接”视为兼容性保证，也不要直接安装不匹配的包。

优先升级到受支持的系统。如果必须保留旧系统，请自行核对客户端官方的系统要求、维护状态和协议支持。本站没有针对这些旧系统提供单独验证过的安装方案。

## 四、路由器与 OpenWrt

OpenClash、Passwall 等路由器方案需要根据设备、固件、内核版本和节点协议自行配置。下载页的一键导入面向已接入的桌面和移动客户端，不会直接配置路由器。

在其他软件中使用订阅时，请先确认它支持本站节点所用协议，以及对应的配置格式；不要直接混用不同客户端导出的配置文件。

## 五、鸿蒙与其他系统

是否能安装安卓 APK，取决于设备实际运行的系统及兼容能力。支持安卓应用的系统可以核对 CMFA 的安装要求；鸿蒙 NEXT 不能直接按安卓 APK 教程操作，本站目前没有提供对应的已验证安装包和一键导入入口。

其他设备、信创系统或处理器架构也应先核对系统和客户端兼容性，不要根据系统名称直接判断能否运行。

## 六、反馈问题时提供什么

请提供设备型号、系统版本、处理器架构、客户端名称和版本，以及错误文字。本站可以协助核对账号和订阅状态；未覆盖的平台，需要同时参考相关客户端或固件项目的官方文档。

不要在公开截图、论坛或工单附件中暴露完整订阅地址。
