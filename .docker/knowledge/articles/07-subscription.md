# 订阅导入与使用教程

安装客户端和导入订阅是两个步骤。先在 [客户端下载页](/clients) 安装对应客户端，再用自己的本站账号获取订阅。

## 一、一键导入

1. 登录本站，在仪表盘确认套餐有效期和剩余流量。
2. 打开侧栏“客户端下载”或首页“下载与导入”，选择设备。
3. 确认客户端已经安装并手动打开过一次。
4. 点击页面上的“一键导入”按钮，允许浏览器打开对应客户端。
5. 在客户端确认保存，选中刚导入的配置，再选择节点并开启连接。

下载页对应的客户端为：桌面端 Clash Verge Rev、安卓 Clash Meta for Android、iPhone / iPad sing-box。原仪表盘的“一键订阅”入口仍可使用，新手建议从下载页完成安装与导入。

## 二、手动导入

如果浏览器无法拉起客户端，点击下载页的“复制订阅地址”。自动复制失败时，展开“手动导入地址”自行复制。

### Clash Verge Rev

进入订阅页面，将地址填入订阅 URL 输入框并导入，完成后选中配置。

### Clash Meta for Android

进入配置，新建 URL 配置，粘贴地址并下载 / 保存，再选中配置。

### sing-box

新建远程（Remote）配置，将地址填入 URL，保存后选中配置。

界面名称会随客户端版本略有变化。请使用完整的个人订阅地址，不要使用安装包地址、下载页地址或教程文字。本站无需通过第三方网站转换订阅。

## 三、导入之后还要连接

- **Windows / macOS / Linux**：按客户端说明开启系统代理，选择节点后实际访问网站。需要额外的 TUN 等功能时，按客户端官方说明配置。
- **Android / iPhone / iPad**：在客户端启动连接，并按系统提示允许该客户端创建 VPN 配置。

浏览器成功打开应用、客户端成功保存配置，只表示相应步骤已完成，不表示所有应用已经联网。退出桌面客户端前先关闭系统代理；移动端不用时在客户端断开连接。

## 四、更新订阅与重置链接

日常使用时，在客户端的订阅 / 配置页面更新远程配置，获取最新节点。如果你在本站重置了订阅链接，需要从下载页重新获取新地址，并替换客户端中的旧订阅。

订阅地址只供本人使用。不要公开发布、转发给他人或上传到不可信的订阅转换服务。

## 五、常见提示

- “未登录或登录已过期”：重新登录后再获取订阅。
- “当前订阅不可用”：检查套餐、剩余流量及账号状态。
- “请求超时 / 网络连接失败”：确认本站可访问，点击“重新获取订阅”或切换网络重试。
- 客户端提示配置错误：核对客户端名称、版本和完整订阅地址。

更多排查步骤见“导入失败怎么办？用不了，或者只有几个节点的看这里”。
