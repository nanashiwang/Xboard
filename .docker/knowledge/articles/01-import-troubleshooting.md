# 订阅导入失败或节点无法连接怎么办？

先打开 [客户端下载与导入页面](/clients)，选择你的设备。Windows、macOS 和 Linux 使用 Clash Verge Rev，安卓使用 Clash Meta for Android，iPhone / iPad 使用 sing-box。各平台要求和安装包以下载页为准。

## 一、点击“一键导入”没有反应

1. 确认已经安装对应客户端，并手动打开过一次。
2. 回到下载页，登录本站账号，点击对应的“一键导入”按钮。
3. 浏览器询问是否打开客户端时，确认应用名称后允许打开。
4. 如果在微信等应用内打开页面，请改用系统浏览器；iPhone / iPad 建议使用 Safari。
5. 仍然没有反应时，点击“复制订阅地址”，在客户端添加 URL 或远程订阅。浏览器不允许复制时，展开“手动导入地址”后自行复制。

## 二、页面提示订阅不可用、未登录或请求超时

- **未登录或登录已过期**：回到用户中心重新登录，再打开下载页。
- **当前订阅不可用**：在仪表盘检查套餐有效期和剩余流量；账号受限时通过工单联系支持。
- **请求超时或网络连接失败**：确认本站可以正常打开，点击“重新获取订阅”；也可以切换 Wi-Fi / 移动网络后重试。

反复点击按钮不会修复过期套餐或已用完的流量，请先处理页面提示的原因。

## 三、客户端提示不支持的协议或配置错误

如果出现 `unsupported proxy type`、无法解析配置，或只有少量节点显示，请先确认客户端名称和版本。旧版 Clash for Windows、Clash for Android 的协议支持可能不完整，建议使用下载页提供的客户端。

使用“复制订阅地址”获取的个人地址添加远程订阅，不要把下载页地址、安装包链接或教程文字当成订阅地址。不同客户端的配置格式不同，不要直接把其他客户端导出的配置文件混用。

升级客户端前先保存需要保留的配置；通常无需先卸载并删除全部数据。

## 四、导入成功，但节点仍然无法连接

1. 在客户端确认保存，并选中刚导入的订阅配置。
2. 更新一次订阅，确认能看到节点列表。
3. Windows / macOS / Linux 按客户端说明开启系统代理；安卓和 iOS 启动连接，并允许该客户端创建 VPN 配置。
4. 测试节点延迟，切换一个节点，再实际访问需要使用的网站。
5. 如果使用 IPv6 专用节点，检查当前网络是否支持 IPv6。

**能拉起客户端、能看到节点或有延迟数值，都不等于所有应用已经连接成功。** 如果仍有问题，请通过“我的工单”提供设备系统、客户端名称和版本、错误文字及发生时间；不要在截图中暴露完整订阅地址。

更多步骤见使用文档中的“订阅操作指南”和“节点选择与使用教程（新手必看）”。
