# Agent Note: FriendHosting 普通套餐节点接入

Status: implemented

## Problem

用户要求将 FriendHosting 日本、荷兰以及命名为「罗马」的新服务器加入四档普通套餐，并排除独享套餐。生产普通套餐对应权限组 1–4，独享对应组 5；不能因复用已有美国后端记录而继承独享授权。「罗马」的实际出口国家为 RO，订阅按罗马尼亚标注，机器名保留用户原命名。

## Decision

复用现有第一阶段 TLS / WebSocket 入口，通过每台独立 WireGuard peer 到 xboard-node。公开订阅记录与隐藏机器后端均只允许权限组 1–4，不创建固定出口池记录。隐藏阶段完成真实代理和独享身份拒绝检查后才公开，再加入现有探针。

| 出口 | 机器 | 公开 → 隐藏 | WireGuard |
| --- | --- | --- | --- |
| 日本 185.39.31.75 | #18 | #354 → #353 | 10.79.0.18/32 |
| 荷兰 185.198.165.162 | #19 | #356 → #355 | 10.79.0.19/32 |
| 罗马尼亚 94.131.17.12 | #20 | #358 → #357 | 10.79.0.20/32 |

三台均约 458 MB 内存，使用现有已验证的原生二进制与非 root systemd 服务，避免额外容器运行时。后端 31443 仅允许隧道入口或回环；SSH 3333 保持原登录方式。新 peer 使用精确 /32，不改变任何服务器默认路由。配置及私钥仅在受限目录保存。

## Existing decision audit

[第一阶段架构](../../implemented/architecture/2026-10-17-stage1-replacement.md)部分重叠，继续复用入口与防火墙约束；[固定出口池](../../implemented/feature/2026-10-19-owned-fixed-exit-pool.md)说明独享分配边界，本次不扩池。荷兰、罗马尼亚完全复用本文原日本接入决定，原地扩充对象和验证，不创建同义笔记。本地未提交香港迁移记录属于此前工作，保留其原归属。

关联提案：[四档套餐第三方拓展线路](../../proposed/architecture/2026-10-21-tiered-upstream-route-family.md)规划新增另一组出口；本文已实施的自建与独享边界继续保留，第三方尚未上线。

## Alternatives considered

- 出口公网直接提供代理可以绕开共享入口，但会新增独立客户端协议、证书及暴露面；本次复用现有订阅与加密中转契约。
- 克隆美国节点后保留全部权限组操作简单，但美国后端已包含固定套餐授权；必须显式重置为普通套餐组并验证独享 UUID 拒绝。
- 容器部署便于镜像管理，但新机内存有限且已有原生节点安装惯例，因此复用原生服务与受限配置。

## Testing

每台均以三名普通账号验证严格 TLS 的 ipify、Cloudflare 国家/出口和 gstatic HTTPS，以及 UDP DNS；独享账号和无效 UUID 均被拒绝。荷兰、罗马尼亚两种客户端五组订阅共 20 项检查通过。最终普通套餐节点数 17/18/19/20，独享仍为原固定出口与香港备用。原线路抽查及旧节点关键配置、套餐参数对照备份通过。

20 条质量探针与 16 条入口隧道映射已保存并核对实际回报。每次本机及 NAS 采样中的超时、TLS 失败和吞吐结果保留原值，不根据心跳强制认定稳定；详见[日本记录](../../../../progress-log.md#2026-10-21friendhosting-日本节点接入)与[欧洲节点记录](../../../../progress-log.md#2026-10-21荷兰与罗马尼亚节点接入)。

## Consequences

复用现有协议和机器管理，降低独立证书与客户端迁移成本，同时增加 peer、路由和监控映射的维护工作。共享入口仍是公共单点。短期检查不证明大陆各运营商性能、长期容量或整机重启恢复。备份含敏感配置，不提交仓库；撤回时只处理新增条目，不能恢复整库或覆盖后来新增的其他节点。

新路径未同步至旧香港入口，回切前需同步并验证，或隐藏三条 FriendHosting 节点及撤下探针。运维位置和局部回退见[日本节点](../../../../docs/zh-CN/installation/japan-node.md)、[欧洲节点](../../../../docs/zh-CN/installation/europe-nodes.md)。
