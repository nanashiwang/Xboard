# Agent Note: 美国出口退租与三台保留服务器重新分配

Status: implemented

## Problem

用户不再续费原普通美国出口及其余独享服务器，指定 216.36.108.128、192.220.24.147 服务四档普通套餐，216.36.108.173 服务独享套餐。线上只存在一个独享绑定，当前占用旧出口 17；直接关闭旧池会中断该用户。三个目标已接入原入口与独立监控，无需新建服务器或重建协议。

## Decision

复用公开源 324/323 与后端 337/336，名称改为美国01/02、倍率保持 2×，开放组 1–4/6。源 322、后端 335、别名 348 和出口 14 留在固定池；保留原美国10编号和组 5/6 隔离。其余美国源、后端及固定别名停止授权和展示，数据保留。固定绑定在套餐锁与同一数据库事务内迁至出口 14，保留订单预留字段和全部用户权益；固定套餐容量从 15 收敛为每出口实际上限 5。香港备用与其他国家、第三方线路保持。

切换前核对精确节点/IP映射、目标健康、实际代理出口、占用上限，生成一致性 SQLite 备份和局部字段快照。切换后验证四档订阅、真实代理、普通/固定互斥和退役路径拒绝，清理临时 QA 身份并验证撤权。监控范围同步移除退役线路，不伪造健康。仅通过已有 GitHub Actions 凭据执行固定范围操作，不把凭据导出至本机。

## Existing note audit

[套餐拆分](../../implemented/architecture/2026-10-21-owned-us-package-split.md)部分被取代：两个普通/十一个固定的配置改为两个普通/一个固定，隔离与监控组仍成立。[固定池](../../implemented/feature/2026-10-19-owned-fixed-exit-pool.md)部分重叠：保留每出口五名额、真实健康与事务绑定。[命名](../../implemented/simplification/2026-10-22-node-names-and-residential-rate.md)部分取代普通美国01/02的物理对应，其他名称与倍率保留。[第三方分档](../../implemented/architecture/2026-10-21-tiered-upstream-route-family.md)、[日本线路](../../implemented/architecture/2026-10-21-friendhosting-japan-node.md)不改；[节点监控](../../implemented/feature/2026-10-18-node-quality-probes.md)复用且仅收敛自建监控范围。没有相关活跃提案需要合并。既有未提交香港/桌面内容保持原归属。

## Alternatives considered

把旧公开记录直接指向新后端可以保留旧节点 ID，但会复制路径、监控映射并增加配置漂移风险；采用已成功接入的新服务器原记录，只复用普通显示名称。保留全部旧池直到自然到期可以少做迁移，但违背用户退租意图且会继续分配即将过期的 IP，因此先迁移后停止分配。

## Testing

生产只读检查确认13个自建美国出口中有1个既有固定绑定。预检40650776322的三个目标与香港备用共四条完整代理路径、每条Cloudflare/Google双目标均通过。应用40650912219已保存一致性SQLite备份（integrity_check=ok）、在同一事务迁移1个绑定、收敛固定池及权限；后续37项真实代理/拒绝全部通过，复验40651967026的同37项再次通过。

本地PHP 8.2.33容器执行Dedicated/Payments共67项测试、412断言通过，其中新四项覆盖预留字段保留、客户权益不改、授权隔离、超容量、过期健康和备份失败的整事务拒绝。Python两项回归覆盖线上[vless]前缀和提示行，及多余/重复真实节点不能被过滤掩盖。PHP组合语法、Python编译、Actions语法和笔记门禁通过。

首次订阅验收使用仅有PHPDoc但未实现的User.subscribe_url属性，改为已有Helper::getSubscribeUrl；下一轮发现线上启用[vless]前缀与流量提示，解析器按实际输出规范化后仍精确比较数据库节点全量名称。两次QA分配遇原NAS健康判定暂时失效，因此增加最多5分钟的只读等待；不刷新checked_at、不强制healthy、不放宽原阈值。每次失败均撤销临时账号，清理支持历次QA身份和迟到统计。最终40655295874已成功：五档实际Sing-box订阅、37项代理/拒绝、9项QA撤权全部通过；30账号、5套餐、55订单对照一致（仅预期容量调整），最终目标健康且占用1/5。用户补充NAS认证后，现场确认原探针存在面板/检查超时，也已有三目标成功的HTTPS与256KiB传输；从NAS通过现有模块对固定目标做三次独立真实检测并原样上报，全部成功，无配置或阈值修改。详细结果见[进展](../../../../progress-log.md#2026-10-28美国出口退租与替换)。

## Consequences

普通套餐依然有两个美国出口与四个非美国自建出口；固定池只剩一个美国IP，没有另一个美国固定故障备用，香港公共备用保留。两普通出口共用主入口，原CF美国备用退出。独享名额从15收敛为实际5，不变更价格或用户已购权益；健康探针波动仍会暂停固定授权/分配。

自建NAS完整路径探针与入口采集均收敛为7条。入口对保留的10.79.0.12/13/14隧道逐项核对实际WireGuard端点为三个指定公网IP，备份配置后仅重启采集器；连续7peer上报成功，业务Nginx/WireGuard保持active。旧WireGuard、Nginx路径和数据库记录保留，旧后端已撤权并停止下发。

宿主备份为/root/Xboard/backups/us-retirement-20261028/before-w_b3m_68.sqlite；容器storage/app/backups/us-retirement-20261028/保存before.json、applied.json及受限QA清单；入口/root/xboard-us-retirement-20261028/保存采集器旧配置。回退先核对当前绑定、订单与健康，只恢复本次字段；不得整库覆盖之后的用量/订单。apply标记阻止重复执行，后续检查使用verify/status。

服务商账单自动续费不由Xboard节点配置控制；本轮退役不代表已在服务商后台关闭续费或销毁服务器。客户端需更新原订阅后选择美国01/02；不更新仍指向已撤权旧服务器。配置和运维工具更新不产生应用或客户端新版本，不触发应用镜像部署或GitHub Release。
