# Agent Note: 恢复独享出口的 NAS 探针面板连接

Status: implemented

## Problem

用户明确要求恢复 Xboard 独享套餐出口 216.36.108.173。套餐仍允许销售、容量五个且占用零，但唯一固定出口缺少有效健康观测，购买接口按现有容量规则隐藏套餐。出口 xboard-node、31443 监听及 WireGuard 握手正常；NAS 的 1.1.0 探针仍访问旧面板 taige.us，持续出现面板网络错误，完整线路样本已过期。

## Decision

复用当前探针、令牌、监控账号、七条节点范围、镜像和测速预算。NAS 面板地址使用已部署的 capybarago.uk；同一令牌严格验证新域配置接口后，备份受限 agent.json，仅替换 panel_url，原子写入并只重建探针容器，保证绑定文件指向新 inode，保留 state。健康与可售容量继续由自然运行的真实检测及现有 dedicated:check 恢复，购买列表仍使用原容量保护。

不新增 SOCKS5 服务，不重新接入或重建固定池，不修改套餐、用户、计量、容量、节点身份或健康阈值，不手工写 healthy/checked_at。备份含凭据，只保留在 NAS 受限目录，仓库记录位置和非敏感摘要。

## Existing note audit

[节点质量探针](../../implemented/feature/2026-10-18-node-quality-probes.md)部分重叠，保留外部实际路径、独立身份和传输预算；[固定出口池](../../implemented/feature/2026-10-19-owned-fixed-exit-pool.md)部分重叠，保留两次独立成功及五分钟健康有效期；[美国出口退役](../../implemented/architecture/2026-10-28-owned-us-retirement.md)保留一个固定出口与香港备用；[双域面板](../../implemented/architecture/2026-11-02-hub-application-domain-split.md)提供已部署同源面板，新域迁移未同步这个外部运行配置是本轮故障边界。未发现相同恢复任务的活跃提案；其他入口及客户端提案不纳入。

## Alternatives considered

把 fixed exit 强制设为 healthy 能立即显示套餐，但绕过真实代理与身份检查，且下一轮会再次失效，因此不采用。改用源站直接探测可以避开家庭网络，但会改变观测位置与验证范围；当前 NAS 到 Go 的严格认证请求成功，先保留原观测位置。给探针新增自动多入口能力可以减少未来单域故障，但需要新配置契约和独立回归，不是本次恢复的必要条件；本轮仅修正过期运行配置。

## Rollback

NAS 备份目录为 `/home/nanashiwang/xboard-node-probe/backups/20261105-panel-origin-1793812749`，含受限 agent.before.json、传输间隔快照和非敏感操作摘要。回退须先核对当前配置仍为本次内容，恢复 agent.before.json 的原权限/所有者，再于原目录只重建 xboard-node-probe 服务；不替换 state，不回放旧采样。旧域当前不可达，回退只恢复配置而不保证服务恢复。

## Consequences

外部探针运行配置不会因网站主域迁移自动更新，迁移后须在探针网络上验证认证、实际节点检测和上报。单文件 bind mount 原子替换后需重建容器以切换 inode，仅重启进程不足以保证读到新文件。此处沿用单面板配置，没有增加自动域名切换；NAS 网络、面板或节点仍可能波动。独享仍只有一个美国出口，没有第二个美国固定故障备用；本轮未执行真实客户支付和新购后的订阅验收。
