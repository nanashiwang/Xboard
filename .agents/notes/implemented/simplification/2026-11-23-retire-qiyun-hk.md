# Agent Note: 退役七云香港面板机器与香港01

Status: implemented

## Problem

七云香港 SID 3 已到期，唯一的公开线路「香港01」掉线，仍在订阅和 NAS 探测范围内。用户已指定删除机器和节点。

## Decision

在生产数据库备份后，以同一事务删除精确匹配的机器 3、后端 338、公开入口 325，并清理对应的探针与入口映射。保留节点统计历史和其他出口权益。

## Alternatives considered

通用机器删除会留下脱离机器的后端与公开入口。只隐藏入口会留下后台记录及探测任务。

## Testing

从面板复核三个 ID 均消失，其他节点内容、独享绑定与监控范围逐项对照。实测剩余线路的出口和 UDP DNS。

## Consequences

香港从普通套餐和原固定出口的备用选择中消失。恢复需按备份局部恢复机器、节点与监控映射。

本决定取代[美国出口退租决定](../architecture/2026-10-28-owned-us-retirement.md)中的香港备用配置，延续[旧节点清理](2026-11-22-remove-retired-node-rows.md)保留历史统计的做法。共享跳板另有五条普通线路和一条固定出口。
