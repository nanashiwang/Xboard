# Agent Note: 节点质量统一为后台完整页面

Status: implemented

## Problem

仪表盘监控卡片与侧栏节点质量重复；侧栏打开大弹窗，导航和滚动方式与其他管理界面不一致。用户要求删除仪表盘监控区块，将节点质量作为正常页面展示。

## Decision

仅保留侧栏入口，在现有后台主内容区显示同源节点质量视图。兼容固定版本管理前端的首页路由，通过 `#/?page=node-quality` 保存页面状态，支持刷新和前进后退；旧 `#node-quality` 入口转到新地址。挂载独立内容和标题，不重写 React 管理的节点或编译子模块。离开页面销毁嵌入视图，不在仪表盘重复请求监控接口。节点历史在页面内显示，保留一次性凭据确认弹窗。

复用现有鉴权、探针 API、数据、采样和统计；同源嵌入视图跟随后台主题。升级上游管理前端时必须复验内容区挂载、侧栏、主题、登录及窄屏。

## Existing decision audit

[探针功能决策](../feature/2026-10-18-node-quality-probes.md)部分重叠：本决定替代其首页卡片与明细弹窗的展示选择，其权限、数据、采样、预算和独立视图维护约定继续有效。入口架构与 Clash Meta DNS 决策无关；既有未提交迁移文档不动。

## Alternatives considered

- 直接跳独立页实现简单，但丢失现有侧栏和后台导航，不满足与其他管理界面一致的要求。
- 改编译后的上游子模块可插入路由，但会引入手工维护的编译分支；沿用本仓库已有扩展边界，使用上游支持的首页查询状态。
- 只移除卡片、保留弹窗工作量最小，但未解决用户明确指出的弹窗交互问题。

## Verification

本地实际后台壳已验证仪表盘无监控卡片；入口脚本不再调用监控 API。侧栏进入完整内容页且正确高亮；刷新、前进后退、其他菜单切换、明细返回、深浅主题、窄屏与未登录权限通过真实后台壳验收（退出登录后无残留视图）。探针 API 回归 13 项测试、71 个断言通过，数据和监控功能保持原语义。

## Consequences

依赖固定版本后台的 DOM 挂载边界；失去挂载目标时必须保持原页面可用。内页样式需要与后台统一，异步历史请求不得在返回列表或切换账号后重新展示旧数据。
