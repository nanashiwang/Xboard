# Agent Note: 节点短名称与美国家宽倍率

Status: implemented

## Problem

用户要求国家、倍率为核心，仅原生 IP、家宽单独标明，并明确全部 13 个自建美国出口标家宽、按 2 倍率。旧名称含供应商、入口阶段与内部 U 编号，客户端列表过长；只改显示倍率会与后端计费不一致。

## Decision

2026-10-28 的[美国出口退租与替换](../../implemented/architecture/2026-10-28-owned-us-retirement.md)部分取代本文的物理出口数量与对应关系：普通美国01/02改为 #324/#323，固定池仅保留出口14（216.36.108.173），原权限隔离、每出口五名额与2×计量约束保留。以下原选择与验收记录作为历史依据。

采用“国家两位稳定编号｜倍率×｜可选属性”。国家采用实际出口；编号按国家分配并冻结，跨套餐保持一致。同一固定出口的监控源记录和客户别名同名，但在各自订阅范围不能重名。普通美国 01/02 对应 #319/#148，其余自建美国 03–13 对应固定池；拓展美国 14–21，第三方原倍率保持。

家宽按用户确认的运营分类，13 个自建美国对应的后端、公开源与固定别名均改 2×，分时倍率保持关闭。固定套餐文案同步，不改既有已入账用量、价格、额度、身份、权限与固定绑定。香港 U36/U37 沿用上游声明的原生 IP，未独立核验；这些属性不构成独立住宅认证或物理独占证明。

UDP 与轻量限速不再占据名称，实际限制和运维映射仍保留；不改原始上游名称/指纹、路由、UUID 或入口。探针/保护器依靠节点 ID、parent 和 tag 保持关联。不会因纯显示/倍率变更重启节点程序。

旧 dedicated:attach-owned 初始导入命令有 1 倍率保护，本轮维持其拒绝行为，不为此次配置更新扩大到应用镜像升级；当前 2 倍池不得重跑旧命令，新接入需要另行适配和验收。`dedicated:prepare` 及其 plan.json 继续保留原 1× SOCKS 初始化契约，未只改模板说明而让新建后端仍扣 1×；该历史流程同样不能用于重建当前 2× 自建池。

## Existing decision audit

- [拓展线路](../../implemented/architecture/2026-10-21-tiered-upstream-route-family.md)：部分取代名称组成和展示限制的位置，保留来源信任、额度保护与协议限制。
- [固定池](../../implemented/feature/2026-10-19-owned-fixed-exit-pool.md)：仅美国计费参数和名称改变，固定分配、容量、权限和健康规则不变。
- [美国拆分](../../implemented/architecture/2026-10-21-owned-us-package-split.md)：两个普通与十一个固定出口边界继续成立。

## Alternatives considered

- 国家和倍率最短，但同国同倍率会重名；Clash 代理名称与 Sing-box tag 直接使用名称，因此加两位编号。
- 保留自建/拓展或供应商可帮助区分来源，但用户明确收窄字段；保留内部 ID/tag 与运维清单，客户端只展示指定信息。
- 只把家宽名称写成 2× 容易执行，却不会修改后端实际扣量；同步后端、公有源、固定别名和套餐说明。

## Testing

实际应用 71 个名称和 39 条倍率记录，对应 13 个自建美国物理出口的后端、公有源与固定别名。四档两格式真实 HTTPS 订阅共 8 项均成功，14/22/34/47 条名称唯一；独享回滚事务读取为一个 2× 美国别名和 1× 香港备用。135 条节点非目标字段、25 个既有用户权益、49 个订单、两套探针配置保持；五个套餐仅授权倍率文案变化。完整配置见[节点映射](../../../../.docker/node-presentation.json)。

13 条家宽与两条对照共 15 条实际代理最终 HTTP 200。首轮 4 次未完成且未扣量，稍后重试全部成功；计费使用完整成功请求的原始应用字节，排除 SOCKS 握手。家宽原始 16,474 字节对应 32,948 字节扣量，日本 1× 对照 1,167 字节、第三方 2× 对照原始 2,408 字节均与逐用户上传/下载及统计一致。五个 QA 账号已删除，旧身份的真实请求确认拒绝；非客户扣量。

初次 SQLite 更新遇写锁，事务回滚；有限 busy timeout 和起始写锁重试后应用成功，备份完整。流程不直接修改固定分配，期间既有健康调度发生 exit_failed 从出口 7 迁至 8；原分配规则保留，不能称绑定始终未变。真实探针与保护配置保持，未手工标绿。纯字段变更不触发配置同步或节点重启，应用镜像未更新。

回退材料保留在生产容器 storage/app/backups/naming-20261022/；只恢复授权字段与倍率文案，不覆盖新增订单、用量或分配。

## Consequences

改名可能使客户端按名称保存的当前选项失效，需要刷新订阅后重选。新上报流量按新倍率，已入队统计使用旧倍率快照；不追溯扣费。展示属性来自用户或上游声明，未作独立 IP 属性认证。旧导入命令拒绝 2 倍池的边界必须保留。
