# Agent Note: 家宽代理保留用户中心布局

Status: implemented

## Problem

用户反馈「我的代理」跳到独立页面，丢失侧栏，和其他页面割裂；要求统一为「家宽代理」并保留用户中心布局。

## Decision

既有 Vue 用户中心路由承载 React 代理组件，沿用原侧栏、页头、登录守卫和移动端菜单。共用组件以 mount/unmount 接口挂载在内容区域，卸载和 KeepAlive 停用时清理轮询及凭据。旧 `/proxies` 地址仅兼容跳回 `/#/proxies`，菜单切换不再触发整页导航。资源 URL 由构建摘要固定，失败可以重试。

## History audit

[正式销售](../../implemented/feature/2026-11-18-residential-proxy-sales.md)继续负责资产、账务和节点授权；本篇接管页面宿主与导航方式，不改销售接口。[原预览](../../implemented/feature/2026-11-18-residential-proxy-workspace.md)保留历史视觉参考。

## Alternatives considered

复制一份侧栏到独立页最省接入工作，但会形成两套导航、主题和用户状态，仍有割裂。iframe 可复用原独立页，但带来滚动、弹窗和会话退出的边界问题；使用组件挂载保留单个页面滚动与原导航生命周期。

## Validation

点击侧栏仅更新 hash，侧栏仍在；离开、返回、退出登录不残留重复轮询或认证数据；旧链接、登录重定向和移动布局正常。官网与客户端名称一致，相关检查与构建通过后按既有流程发布。

## Consequences

上游主题仅有编译产物，Vue 渲染函数别名必须由测试核对；维护可读路由补丁并在构建中精确替换，避免静默失效。

本地验证：网站/代理 PHP 16 项、110 断言通过；客户端前端 78 项与脚本 17 项通过；新增宿主生命周期 4 项通过。浏览器确认桌面概览/详情保留侧栏，切换仪表盘并返回正常；390px 手机详情和折叠菜单正常。生产与 0.1.16 发布待独立核实。

卸载后的旧请求即使返回认证失效，也不得清除后来建立的新会话；宿主认证回调同时检查活动标记与挂载代次。生命周期测试覆盖离开后旧回调和返回后旧回调均无副作用。
