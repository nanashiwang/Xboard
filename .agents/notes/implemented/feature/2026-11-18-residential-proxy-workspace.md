# Agent Note: 家宽代理概览、详情与客户端预览

Status: implemented

## Problem

用户希望以两张代理管理截图为参考，设计独立代理商品的官网概览、详情和配套客户端。用户明确本轮先完成可交互设计预览；另行授权服务器端点配置，不等于授权接入真实订单或修改已售套餐。

## Decision

独立静态预览放在 docs/previews/proxy-workspace，复用现有卡皮巴拉图标、浅蓝色视觉和侧栏习惯。三个 hash 路由共用示例端点状态，支持状态筛选、搜索、导出、协议切换、复制、重命名、密码显示与重置、模拟购买/续费、客户端模拟连接与失败场景。使用文档保留地址和虚构认证，不读取真实账号、不修改系统代理。

产品呈现“家宽固定 IP”，39 元/月、最高 100 Mbps、不限累计流量。用户要求不在主界面强调每 IP 十账号分配细节；不写“独享 IP”。SOCKS5 与 HTTP 是同一端点的两种连接方式，切换时地址、端口和密码不变。不限量用累计数值，不画额度圆环；没有真实可用率、ISP 和并发数数据，避免照搬这些承诺。

## History audit

- [山水客户端](../../implemented/feature/2026-10-26-capybara-scenic-home.md)部分重叠，复用品牌，新增代理工作区设计；不替换真实首页、原生连接或订阅能力。
- [自建固定出口池](../../implemented/feature/2026-10-19-owned-fixed-exit-pool.md)部分重叠；真实原套餐仍按五名额和既有权益运行，不把十端点预览误写为原套餐容量调整。
- [多入口恢复](../../proposed/architecture/2026-11-02-client-entry-resilience.md)无关；不改变恢复机制。
- [独立端点部署](../architecture/2026-11-18-dual-protocol-proxy-endpoints.md)是后续明确授权的运维任务，和页面 API/订单接入分开验收。

## Alternatives considered

直接改正式客户端和官网可减少重复搭建，但用户已选择先评审三页预览，且真实代理商品权益接口尚未实现。保持独立目录，避免示例状态进入正式用户界面。

复制参考图全部字段最贴近原图，但并发升级、自动扣费、住宅 ISP 认证、100% 可用率没有现有数据和能力支持。只保留明确规格及可解释的示例趋势，使用手动续费。

## Validation

Playwright验证1440桌面以及390/320/760/1180像素的三路由无页面横向溢出；搜索空态、状态筛选、协议同步、密码显隐、转义重命名、重置取消、日历月续费、待开通禁用、客户端模拟连接/断开/失败与空列表通过。JS语法、工作流笔记检查通过；只有静态资源，无业务API调用。

## Consequences

浏览器预览不证明原生客户端连接或真实服务端购买可用。正式实现需要端点库存、订单权益、按端点到期撤权、用量和检测接口；不能直接将预览 JSON 作为生产数据。
