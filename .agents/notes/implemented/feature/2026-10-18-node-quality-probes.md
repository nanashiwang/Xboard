# Agent Note: 独立节点质量探针与管理员检测面板

Status: implemented

## Problem

公开节点继承隐藏后端心跳，入口异常时仍可能显示在线。用户要求在 Xboard 增加真实代理检测，并指定家庭网络 NAS 作为首个常驻探针；该能力属于 Xboard，与其他项目无关。

## Decision

展示决策已由[节点质量完整页面](../simplification/2026-10-18-node-quality-page.md)局部取代：仪表盘卡片与大弹窗退出，改为侧栏完整页面及页面内历史；下述初始展示方案保留其取舍背景，权限、采样、数据和运维决策继续有效。

面板管理探针、节点范围和检查历史；外部 Python 探针在 NAS 运行 sing-box，经固定单节点出口执行 HTTPS 及有预算的上下行检测，使用独立、可撤销、仅能获取自身任务及提交结果的令牌。复用现有订阅权限与 SingBox 协议构建，不更改用户节点选择、后端在线状态或生产路由。

首页看板卡片及侧栏入口复用管理员登录与 API 权限，管理和历史在后台内对话框展示，提供探针位置、数据时效、节点成功率、耗时、传输完成率和故障/恢复事件。未知、配置不支持、账号不可用、探针失联不能显示正常。明细保留 24 小时、小时统计保留 30 天，按探针和公开节点分别统计；不主动发送外部消息。

NAS 使用独立目录与容器，不要求特权、TUN 或主机路由修改。探针只有单个节点出站，没有 direct 回退；监控文件权限受限，结果不包含订阅令牌、UUID、WebSocket 路径或原始错误正文。

入口与出口隧道分层观测由[入口观测决策](./2026-10-19-ingress-observability.md)扩展；入口 HTTPS 直连属于独立任务，不改变节点完整代理检测的无直连回退约束。

## Existing decision audit

[第一阶段迁移](../../implemented/architecture/2026-10-17-stage1-replacement.md)部分重叠：复用公开入口和隐藏后端拓扑，但其临时验收脚本不负责持续探测。原有未提交香港入口笔记属于既有迁移任务，保留原归属。项目工作流笔记与运行时检测无关。

## Alternatives considered

- 只增加 ping 或端口检查实施简单、流量很小，但不能发现入口代理鉴权、TLS 或传输失败，因此保留资源监控并增加完整代理请求。
- 在面板服务器直接发起探测无需 NAS，但不能代表用户网络到入口的路径，因此采用外部探针，结果带明确位置。
- 编写 VLESS/WebSocket 加密客户端可减少二进制依赖，但容易偏离实际客户端和协议兼容行为，因此复用现有 SingBox 配置生成与成熟内核。
- 修改上游编译后的管理前端可以直接加入菜单，但会使构建产物变成手工维护分支，因此增加本仓库维护的管理视图和可发现入口，沿用现有登录鉴权。

## Verification

- 普通用户及匿名请求不能管理或读取探针；禁用、轮换令牌后旧凭据失效，越界节点和重放上报被拒绝或幂等处理。
- 实际检测始终绑定指定节点，校验响应与传输字节数；失败、账号无效和探针失联显示正确，状态恢复可追溯。
- 测试覆盖权限、结果统计、过期、重复、失败恢复、配置生成与代理检测；管理页面验证空态、失败、历史、窄屏与登录边界。
- 本地完整 PHP 回归、探针单测及真实内核拒绝直连回退检查通过；管理页面验证登录边界、历史明细、过期状态及 390px 宽度。NAS 已导入 amd64 镜像并执行内核版本检查，生产接入与真实采样另行验收。

## Consequences

测量受 NAS 所在网络、监控账号限速与目标站影响，不代表所有运营商。持续探测消耗流量，传输默认使用小样本并限制频率；需要运维管理令牌、探针升级和账号剩余用量。

最近上传/下载结果独立保存，不被轻量检查覆盖。17 节点默认传输载荷约 408 MiB/天。CLI 可创建独立非管理员账号，30 GiB 总量、365 天有效期、100 Mbps 限速；不自动续费或续额度，耗尽显式失败。需要持续吞吐容量评估或专属线路时另行扩大验证范围。

服务端锁定每探针更新，重复 UUID 和旧采样不改变计数及状态。页面调用失败将现有状态标为过期；缺采不记为成功。历史数据通过现有调度器清理，故障和恢复只记录在本系统，不发送外部通知。

上传或下载失败后，后续仅有轻量 HTTPS 请求成功不能将节点恢复为正常；必须先取得成功的传输复测，再满足连续成功条件。

后台首页使用本仓库维护的扩展脚本挂载到固定版本管理前端的现有看板容器；不改写编译子模块。升级管理端子模块需复验挂载、路由往返、权限失效、深浅主题、窄屏和同源明细对话框。
