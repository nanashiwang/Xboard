# Agent Note: 节点管理按入口与后端分组

Status: implemented

## Problem

管理页把订阅入口、机器后端和独享别名平铺。管理员要同时看懂父子 ID 与权限才能识别同一条线路。

## Decision

在原管理表格内按 parent_id 归组。默认显示入口，详情列出真实后端及关联入口，编辑仍使用原节点 ID 和原表单。提供完整记录视图供逐条管理；原筛选和排序使用完整数据。

## Alternatives considered

按名称或国家合并会误处理重名和共享后端。直接删除后端会破坏下发，只用 CSS 隐藏表格行也会造成全选、分页与手机卡片不一致。

## Consequences

当前 15 条自建节点记录归为 7 条线路。美国共享后端下的独享别名和普通入口可分别编辑。列表的机器信息取自后端，行上的批量操作使用选中入口的原始 ID。搜索、筛选、拖拽排序和「全部记录」均能访问完整记录。孤立节点、可见父节点、断链、循环及多层拓扑保留独立行。

浏览器使用真实管理前端和本地测试接口验收桌面与手机交互；发布验收另核对线上静态资源。[验证记录](../../../../progress-log.md#admin-node-lines-20261122)
