# Agent Note: 卡皮巴拉官网首页与原面板入口兼容

Status: implemented

## Problem

用户希望官网首页采用所提供的蓝天海岸、旅行水豚和木质路牌设计。现有根路由直接加载 Vue hash 用户面板，默认跳转登录；直接替换模板会破坏收藏的登录、注册、套餐和订单链接。

## Decision

仅在内置 Xboard 主题增加服务端渲染的公开首页；无 #/ 路由时显示首页并延迟加载用户面板，任何原 #/ 路由仍启动原 umi.js。首页与面板之间以刷新完成切换，避免两个路由器争用 hash；首页段落锚点不触发面板。注册、登录、套餐、下载入口复用已有地址，不新增身份或定价接口。

图片只承载风景和角色，标题、按钮、功能说明均使用真实 HTML，适配手机、键盘和无 JS。使用参考图生成独立风景横幅，压缩为 WebP；站点不依赖第三方图片域名。不沿用没有当期依据的 50+、全天稳定、无限带宽等断言。

官网下载入口由[卡皮巴拉客户端下载](../../implemented/feature/2026-10-23-capybara-client-downloads.md)接管：电脑优先自有客户端，手机与原 Clash 保留第三方流程，复用已发布安装包。

## Alternatives considered

- 直接使用整张参考截图最接近视觉稿，但文字不可选择、按钮不可操作，手机只能缩放整图，因此只保留插画作为背景，内容由 HTML 实现。
- 新建 /app 面板路径可隔离页面，但须修改原用户路由与所有已保存深链接；保留既有 #/ 契约减少迁移成本。
- 修改压缩后的 umi.js 可复用前端路由，但缺少对应前端源码与构建链；在现有 Blade 入口选择启动模式更易维护。

## Verification

PHP 8.2.33 下首页与客户端下载 15 项测试、91 断言通过；Blade 编译、JS 语法、actionlint 与笔记门禁通过。专项 CI 执行同组 PHP 回归和模板编译。

真实 Laravel/Vue 壳验证 320/390/768/1024/1536px 无横向溢出，手机菜单/Escape、段落锚点、原生 FAQ、深色系统偏好与减少动画可用。注册前进后退、刷新、邀请码填入、套餐未登录保护、下载入口通过；禁用 JS 仍有正文和导航，图片失败仍可阅读，面板资源失败提供重试/返回首页。

回退时 Vue 原路由器先于 hashchange 处理 popstate，会把根页面改写成登录页。启动器在捕获阶段拦截跨页面模式的 popstate/hashchange，停止后续监听并只刷新一次；同一模式内不拦截，由 Vue 或原生段落锚点处理。

正式网络允许访客在 defer 启动脚本到达前点击链接，因此启动器必须重新读取 hash 并同步显示模式，不能只信任 head 的首帧状态；pageshow/bfcache 恢复时清除防重复标志。脚本 URL 使用应用版本，避免修复后继续使用固定 v=1 的缓存。5 项 Node 回归及实际浏览器暂停启动器后点击注册的复现测试通过，防止只用快速本地网络验收。

## Consequences

首页独立轻量显示、真实文字可检索并适配手机；旧面板深链接与身份边界保持。跨首页/面板多一次文档加载。内置 Xboard 模板被用户主题覆盖时需另行适配，其他主题保持原样。页面采用固定浅色风景，原面板深浅主题不变。

首页没有实时节点/套餐数据接口，装饰路牌不是库存保证；价格与实际线路由现有受保护页面提供。构建、Release 与生产验证分开记录；用户后续授权后，修正版 16272a2 已经专项 CI、双架构构建并部署生产 Healthy；两个域名版本及资源核对、登录/注册往返、手机布局和生产延迟启动复验通过，连接超时与完整重测结果见[进展记录](../../../../progress-log.md#修正版上线与最终复验)；未注册真实账号或执行支付。
