# Agent Note: 独立钱包充值订单

Status: implemented

## Problem

桌面钱包和网站共用余额，用户需要直接给钱包充值。

## Decision

钱包用已有设备会话创建独立订单。服务端确定通道、本金和手续费，单笔本金支持人民币 0.01 至 10000 元。沿用现有收银台。验签后的网关通知还须匹配订单通道、实际支付金额和交易号；在同一数据库事务内锁定订单和账户，增加本金并写入完成状态。已取消订单收到确实付款的迟到通知也入账。桌面展示最近十笔充值，付款后可刷新余额。

## Alternatives considered

使用隐藏套餐可复用下单入口，但会触发订阅时长、余额抵扣或换购结算。独立订单只复用收款和已有账户余额，订阅权益和佣金另走原流程。

## Consequences

支持可核对结算金额的易支付、支付宝当面付和 Stripe Checkout。手续费只用于支付。客户端、回跳页和管理员的套餐开通动作都不能直接增加余额。回归从设备鉴权下单和收银台走到公开网关回调，包含错误签名、金额、通道、取消和重复通知。此决定扩展[桌面商店](2026-10-25-capybara-store.md)。
