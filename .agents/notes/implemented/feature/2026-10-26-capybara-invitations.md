# Agent Note: 卡皮巴拉客户端邀请好友

Status: implemented

## Problem

用户希望直接在客户端邀请用户。网站已有邀请码、注册归属、佣金统计和记录，桌面令牌不能调用全权限网站接口；仅提供网站链接仍需要用户来回切换。

## Decision

侧栏新增邀请好友，登录后展示本人邀请码、复制固定官网注册链接和二维码、生成新码、注册人数和佣金统计、分页明细。生成由用户主动触发，不自动消耗邀请码额度；一次性/长期邀请码、注册关闭、生成额度、个人比例和分销比例均读取服务器设置。没有套餐也可以邀请。提现与余额划转从既有官网邀请中心办理，本次不新增资金操作。

Desktop API 继续 client.auth/client.device，只读取本人数据；统计复用网站控制器，邀请码创建抽为共享服务并用事务用户行锁保护额度，保持网页行为一致。原生桥只允许固定操作与有界页码；令牌不传入 WebView，分享链接只含邀请码。网络失败不自动重放生成；切换账号、注销和卸载页面丢弃旧响应及二维码。

## Alternatives considered

- 仅跳转官网邀请页能复用全部功能，但无法在客户端便捷复制分享和查看统计。
- 在 WebView 嵌入官网可减少 UI 代码，但需要全权限网站会话和远端脚本；采用本地 UI 与限定 Desktop 接口。
- 同时实现提现和划转可完整搬迁网站，但引入资金操作及额外确认，本次保留官网入口以专注邀请。
